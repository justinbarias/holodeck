Progressive disclosure for every tool call

Every tool card is one 44 px row until someone asks for more. The row is a real button: tool name, a plain one-line headline, status with icon and word, duration, chevron. Finished cards stay closed, so the answer is never pushed down. More than three calls in a turn fold into one group row.

1 · Streaming: cues arrive one by one

Each row appears the moment its call starts, runs with a growing bar, then settles to Done in place. No layout jump when it finishes.
